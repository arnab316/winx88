================================================================================
 WINX-88  —  PROMOTION-CMS  ADMIN API  (frontend integration reference)
================================================================================

 Module: promotion-cms  = the DISPLAY layer for promotions
         (banners, images, titles, ordering, visibility).
 A CMS card may link to a bonus-engine promotion via `promotionId`.

 AUTH (every route below): Authorization: Bearer <ADMIN_JWT>   (AdminGuard)
 BASE = {{BASE}}/promotion-cms          (e.g. http://localhost:3000/promotion-cms)

 NOTE: request bodies are camelCase. Unknown fields are stripped automatically.

================================================================================
 ADMIN ENDPOINTS  (7)
================================================================================

--------------------------------------------------------------------------------
 1) GET  {{BASE}}/promotion-cms/admin
    List CMS cards (paginated)
--------------------------------------------------------------------------------
 Query params (all optional):
   currency    = string
   isActive    = true | false
   tag         = LIVE | SLOT | SPORTS | FISHING | LOTTERY | TABLE | ARCADE | CRASH | OTHER
   promotionId = int
   search      = string
   page        = number (default 1)
   limit       = number (default 20, max 200)

--------------------------------------------------------------------------------
 2) GET  {{BASE}}/promotion-cms/admin/:id
    Get one CMS card (full detail)
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 3) POST {{BASE}}/promotion-cms/admin
    Create a CMS card.  ALL fields optional.
--------------------------------------------------------------------------------
 Body (JSON):

   // ── link & placement ──
   promotionId           int                  // links to a /promotion engine promo
   currency              string (2–10)
   sequence              int (>=0)             // display order (lower = first)
   tags                  array of: LIVE | SLOT | SPORTS | FISHING | LOTTERY | TABLE | ARCADE | CRASH | OTHER
   eligibleMemberGroupId int

   // ── visibility toggles ──
   displayBeforeLogin    boolean
   displayAfterLogin     boolean
   showRemainingTime     boolean
   allowApply            boolean
   isActive              boolean

   // ── behaviour ──
   redirectTarget        PROMO_CENTER | DEPOSIT | VIP | NONE
   nonEligibleDisplay    GREY | HIDE | DISABLED

   // ── schedule ──
   startsAt              ISO date string   (e.g. 2026-01-01T00:00:00.000Z)
   endsAt                ISO date string
   //  send omit (not "") when empty

   // ── English content ──
   titleEn               string (0–200)
   descriptionEn         string
   contentEn             string
   bannerEnUrl           string   // URL returned by upload-banner (variant banner_en)
   smallBannerEnUrl      string   // URL returned by upload-banner (variant small_banner_en)

   // ── Bangla content ──
   titleBn               string (0–200)
   descriptionBn         string
   contentBn             string
   bannerBnUrl           string   // URL from upload-banner (variant banner_bn)
   smallBannerBnUrl      string   // URL from upload-banner (variant small_banner_bn)

   // ── button visibility ──
   buttonShowWithTitle      boolean
   buttonShowWhenEligible   boolean
   buttonShowInPromotions   boolean
   buttonShowInPromoCenter  boolean

--------------------------------------------------------------------------------
 4) PATCH {{BASE}}/promotion-cms/admin/:id
    Update a CMS card.  Same body as POST (#3), all fields optional.
    Send only the fields you change.
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 5) DELETE {{BASE}}/promotion-cms/admin/:id
    Soft delete (deactivate). Does not hard-delete.
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 6) POST {{BASE}}/promotion-cms/admin/reorder
    Bulk re-order the display sequence
--------------------------------------------------------------------------------
 Body (JSON):
   {
     "items": [
       { "id": 12, "sequence": 0 },
       { "id": 9,  "sequence": 1 },
       { "id": 4,  "sequence": 2 }
     ]
   }

--------------------------------------------------------------------------------
 7) POST {{BASE}}/promotion-cms/admin/upload-banner
    Upload a banner image -> returns its URL. Call BEFORE create/update.
--------------------------------------------------------------------------------
 Content-Type: multipart/form-data
 Form fields:
   file     = <image file>   (required; JPG / PNG / WEBP / GIF, max 5 MB)
   variant  = banner_en | banner_bn | small_banner_en | small_banner_bn   (required)

 Response:
   { "url": "https://.../banner.png", "variant": "banner_en" }

================================================================================
 ENUM REFERENCE
================================================================================
 tags / GAME_CATEGORIES : LIVE, SLOT, SPORTS, FISHING, LOTTERY, TABLE, ARCADE, CRASH, OTHER
 redirectTarget         : PROMO_CENTER, DEPOSIT, VIP, NONE
 nonEligibleDisplay     : GREY, HIDE, DISABLED
 upload-banner variant  : banner_en, banner_bn, small_banner_en, small_banner_bn

================================================================================
 TYPICAL FLOW (admin creates a promo card)
================================================================================
 1. (rule lives in the other module) create the bonus rule first:
        POST {{BASE}}/promotion/admin   -> returns promotion id
 2. Upload each banner image:
        POST {{BASE}}/promotion-cms/admin/upload-banner   (file + variant)
        -> copy the returned "url"
 3. Create the card with those URLs + the promotion link:
        POST {{BASE}}/promotion-cms/admin
        {
          "promotionId": <id from step 1>,
          "titleEn": "Newly Deposit 100%",
          "bannerEnUrl": "<url from step 2: banner_en>",
          "smallBannerEnUrl": "<url from step 2: small_banner_en>",
          "tags": ["SLOT","LIVE"],
          "redirectTarget": "DEPOSIT",
          "displayAfterLogin": true,
          "isActive": true,
          "sequence": 0
        }
 4. Re-order cards on the list page:
        POST {{BASE}}/promotion-cms/admin/reorder
================================================================================
