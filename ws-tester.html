WinX88 Games WebSocket Tester

Quick way to verify the gateway is broadcasting events.

Disconnected

Listens for these events on subscribed games:

  • round:opened — admin called POST /games/round
  • round:closing-soon — round close_time within 30s (cron-driven)
  • round:closed — round close_time hit (cron-driven)
  • round:result-published — admin called POST /games/result/:id
  • round:settled — admin called POST /games/settle/:id
