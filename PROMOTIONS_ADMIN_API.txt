================================================================================
 WINX-88  —  PROMOTIONS ADMIN API  (frontend integration reference)
================================================================================

Two separate modules. Use BOTH:

  • promotion       → the BONUS ENGINE (rules, eligibility, turnover, claims)
  • promotion-cms   → the DISPLAY layer (banners, images, titles, ordering)

A CMS card can link to an engine promotion via `promotionId`.

AUTH (all routes below):
  Header:  Authorization: Bearer <ADMIN_JWT>
  (every /admin route is protected by AdminGuard)

Base URL placeholder below = {{BASE}}  (e.g. https://api.yourdomain.com)

================================================================================
 1) MODULE: promotion        BASE = {{BASE}}/promotion
================================================================================

--------------------------------------------------------------------------------
 GET  {{BASE}}/promotion/admin
 List promotions (paginated)
--------------------------------------------------------------------------------
 Query params (all optional):
   kind      = DEPOSIT | REGISTRATION | PROMOCODE | MANUAL | FREE_REWARD | RELOAD | CASHBACK
   isActive  = true | false
   currency  = string (e.g. BDT)
   code      = string
   page      = number (default 1)
   limit     = number (default 20, max 200)

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion/admin
 Create a promotion (the bonus RULE)
--------------------------------------------------------------------------------
 Body (JSON):
   --- REQUIRED ---
   title              string (3–150)
   kind               DEPOSIT | REGISTRATION | PROMOCODE | MANUAL | FREE_REWARD | RELOAD | CASHBACK
   bonusType          PERCENT | FLAT
   bonusValue         number (>=0, default 0)

   --- OPTIONAL: identity ---
   code               string, UPPERCASE [A-Z0-9_] (2–40)   // promo code
   description        string (0–2000)
   currency           string (2–10)
   bonusTo            BONUS_BALANCE | MAIN_BALANCE

   --- OPTIONAL: amounts ---
   minAmount          number (>=0)   // min deposit to qualify
   applyAmountMin     number (>=0)
   maxBonus           number (>=0)
   rolloverMultiplier number (>=0)   // turnover multiplier
   maxBonusPool       number (>=1)

   --- OPTIONAL: usage limits ---
   memberGroupId      int
   maxUsesPerUser     int (>=1)
   maxUsesGlobal      int (>=1)

   --- OPTIONAL: schedule / targeting ---
   isActive           boolean
   startsAt           ISO date string
   endsAt             ISO date string
   deviceTypes        array of: DESKTOP | MOBILE_WEB | APP
   frequency          ONE_TIME | RECURRING_DAILY | RECURRING_WEEKLY | RECURRING_MONTHLY | UNLIMITED
   cooldownSeconds    int (>=0)
   eligibleGameCategories  array of: LIVE | SLOT | SPORTS | FISHING | LOTTERY | TABLE | ARCADE | CRASH | OTHER
   autoUnlockThreshold     number (>=0)

   --- OPTIONAL: anti-abuse unique checks (boolean each) ---
   uniqueCheckBankAccount, uniqueCheckEmail, uniqueCheckIpAddress,
   uniqueCheckDeviceFp, uniqueCheckPhone

   --- OPTIONAL: verification requirements (boolean each) ---
   requireEmailVerified, requirePhoneVerified, requireProfileVerified

   --- OPTIONAL: chaining / lifecycle ---
   linkedPromotionId  int
   autoApprove        boolean   // false = needs admin approve-claim
   autoComplete       boolean
   allowCancel        boolean
   cancelThreshold    number (>=0)
   limitToProvider    boolean
   checkByWalletBalance boolean

   --- OPTIONAL: amount settings ---
   maxPlayer          int (>=1)
   maximumWithdrawal  number (>=0)
   balanceRequire     number (>=0)
   forfeitType        BONUS | WALLET
   amountCap          number (>=0)
   removeMaxWithdrawLock boolean

   --- OPTIONAL: wagering target ---
   targetType         TURNOVER | DEPOSIT | WIN_LOSS
   targetOption       BONUS_AND_APPLY | BONUS_ONLY | APPLY_ONLY
   capLimitType       AMOUNT | PERCENT

   --- OPTIONAL: CMS visibility hints ---
   payLater           boolean
   displayIfNonEligible boolean
   hideIfEligible     boolean

--------------------------------------------------------------------------------
 PATCH {{BASE}}/promotion/admin/:id
 Update a promotion (all fields optional)
--------------------------------------------------------------------------------
 Body: same fields as POST EXCEPT these cannot be changed after create:
       kind, code, bonusType, currency, bonusTo
 (everything else from the create body is editable)

--------------------------------------------------------------------------------
 DELETE {{BASE}}/promotion/admin/:id
 Soft delete (deactivate). Never hard-deletes (FK safety).
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 GET  {{BASE}}/promotion/admin/:id/claims
 List claims for one promotion
--------------------------------------------------------------------------------
 Query: page (default 1), limit (default 50)

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion/admin/grant-manual
 Grant a manual bonus to a user
--------------------------------------------------------------------------------
 Body:
   userId             int        (required)
   amount             number >=1 (required)
   reason             string (3–500) (required)
   rolloverMultiplier number >=0 (optional)
   bonusTo            BONUS_BALANCE | MAIN_BALANCE (optional, default BONUS_BALANCE)

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion/admin/approve-claim
 Approve a pending claim (for promos with autoApprove=false)
--------------------------------------------------------------------------------
 Body:  { "claimId": int }

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion/admin/cancel-claim
--------------------------------------------------------------------------------
 Body:  { "claimId": int, "reason": string (3–500) }

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion/admin/forfeit-claim
--------------------------------------------------------------------------------
 Body:  { "claimId": int, "forfeitType": "BONUS" | "WALLET", "reason": string (3–500) }

--------------------------------------------------------------------------------
 STATS
--------------------------------------------------------------------------------
 GET  {{BASE}}/promotion/admin/stats/overview     // single-row dashboard summary
 GET  {{BASE}}/promotion/admin/stats/summary      // per-promotion table
 GET  {{BASE}}/promotion/admin/:id/stats          // one promotion's stats

 Shared query params (StatsQuery):
   preset    = TODAY | YESTERDAY | THIS_WEEK | LAST_WEEK | THIS_MONTH | LAST_MONTH | CUSTOM
   from      = ISO date  (required when preset = CUSTOM)
   to        = ISO date
   currency  = string
   status    = ACTIVE | INACTIVE | ALL


================================================================================
 2) MODULE: promotion-cms     BASE = {{BASE}}/promotion-cms
================================================================================

--------------------------------------------------------------------------------
 GET  {{BASE}}/promotion-cms/admin
 List CMS cards (paginated)
--------------------------------------------------------------------------------
 Query params (all optional):
   currency    = string
   isActive    = true | false
   tag         = LIVE | SLOT | SPORTS | FISHING | LOTTERY | TABLE | ARCADE | CRASH | OTHER
   promotionId = int
   search      = string
   page        = number (default 1)
   limit       = number (default 20, max 200)

--------------------------------------------------------------------------------
 GET  {{BASE}}/promotion-cms/admin/:id
 Get one CMS card
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion-cms/admin
 Create a CMS card (the visual promo). ALL fields optional.
--------------------------------------------------------------------------------
 Body (JSON):
   promotionId        int                  // link to engine promotion
   currency           string (2–10)
   sequence           int (>=0)            // display order
   tags               array of GAME_CATEGORIES (LIVE|SLOT|SPORTS|FISHING|LOTTERY|TABLE|ARCADE|CRASH|OTHER)

   displayBeforeLogin boolean
   displayAfterLogin  boolean
   showRemainingTime  boolean
   allowApply         boolean

   redirectTarget     PROMO_CENTER | DEPOSIT | VIP | NONE
   nonEligibleDisplay GREY | HIDE | DISABLED
   eligibleMemberGroupId int

   startsAt           ISO date string
   endsAt             ISO date string

   // English content
   titleEn            string (0–200)
   descriptionEn      string
   contentEn          string
   bannerEnUrl        string   // URL from upload-banner (variant banner_en)
   smallBannerEnUrl   string   // URL from upload-banner (variant small_banner_en)

   // Bangla content
   titleBn            string (0–200)
   descriptionBn      string
   contentBn          string
   bannerBnUrl        string   // URL from upload-banner (variant banner_bn)
   smallBannerBnUrl   string   // URL from upload-banner (variant small_banner_bn)

   // Button visibility
   buttonShowWithTitle      boolean
   buttonShowWhenEligible   boolean
   buttonShowInPromotions   boolean
   buttonShowInPromoCenter  boolean

   isActive           boolean

--------------------------------------------------------------------------------
 PATCH {{BASE}}/promotion-cms/admin/:id
 Update a CMS card (same body as POST, all optional)
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 DELETE {{BASE}}/promotion-cms/admin/:id
 Soft delete (deactivate)
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion-cms/admin/reorder
 Re-order the display sequence
--------------------------------------------------------------------------------
 Body:  { "items": [ { "id": int, "sequence": int }, ... ] }

--------------------------------------------------------------------------------
 POST {{BASE}}/promotion-cms/admin/upload-banner
 Upload a banner image, returns its URL (call BEFORE create/update)
--------------------------------------------------------------------------------
 Content-Type: multipart/form-data
 Form fields:
   file     = <image file>   (required; JPG/PNG/WEBP/GIF, max 5 MB)
   variant  = banner_en | banner_bn | small_banner_en | small_banner_bn   (required)

 Response: { "url": "https://.../banner.png", "variant": "banner_en" }

 USAGE: upload image -> get url -> put url into bannerEnUrl/bannerBnUrl/
        smallBannerEnUrl/smallBannerBnUrl on the create/update call.


================================================================================
 TYPICAL ADMIN FLOW
================================================================================
 1. Create the bonus rule:   POST /promotion/admin
 2. Upload banner image(s):  POST /promotion-cms/admin/upload-banner  (per variant)
 3. Create the visual card:  POST /promotion-cms/admin
       { promotionId: <id from step 1>, bannerEnUrl: <url from step 2>, ... }
 4. Order cards:             POST /promotion-cms/admin/reorder
================================================================================
